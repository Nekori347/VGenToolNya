# VGenToolNya

VGen 画师工作流的 Chrome Manifest V3 扩展。当前公开源码用于独立审查，仍处于开发中；用户尚未验收，不代表汉化已全面覆盖或旧功能已完全无损迁移。

## 构建与安装

需要 Node.js（建议 22 或更新版本）及 npm。

```sh
npm ci
npm run build
```

Chrome 打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，加载 `.output/chrome-mv3`，再刷新 VGen。停用旧油猴脚本以避免重复入口或拦截。可选执行 `node scripts/package.mjs` 复制到本地 `Demo/chrome-mv3`；构建产物不随源码发布。

扩展选项提供预设、主题与 AI 服务商设置。默认使用模拟响应；真实调用需填写自己的 Key、模型与兼容接口地址，关闭模拟并授权接口域名。不要把凭据写入源码或提交到 Git。

## 已实现的功能范围（仍需审查）

- 本地 UI 词典、原文恢复、双语渲染，以及原生文案发现和漏翻管理。
- 输入框预设、AI 翻译编辑器、独立回译、撤回和原值恢复。
- 作品标题、描述、搜索/发现标签及组合预设。
- 常用客户、本地备注、公开客户信息、订单客户增强。
- 聊天已读控制、消息状态、评价生成与原生标签适配。
- 统一设置、旧脚本数据迁移、OpenAI 兼容服务商适配。

## 当前问题与验收边界

汉化仍不完整，二级菜单和弹窗有遗漏；双语字号与排版缺乏充分的组件适配；文字按钮、自绘图标和原有成熟 UI 的还原不足。自动化记录不能替代实际页面和弹窗的人工体验。

真实账户的发送、保存、上传、评价提交、订单修改及已读回执等写入尚未通过用户验收。部分路径只进行源码分析或合成原生状态测试，不能当作真实写入成功。详情见 CURRENT.md。

审查入口见 REVIEW.md。`tests/` 保留测试源码，可用 `npm run check` 和 `npm test` 检查；测试数量不作为产品完成证明。
